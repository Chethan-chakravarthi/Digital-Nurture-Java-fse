# Week 5 - Module 1: HTML5

This module covers the fundamentals of HTML5 as part of the Java FSE Angular curriculum.

## Files Created

1. **index.html** - Main HTML5 page demonstrating:
   - Basic HTML5 structure with DOCTYPE
   - Headings (h1, h2)
   - Paragraphs
   - Horizontal rules (hr)
   - Navigation menu with links
   - Section element
   - Image element
   - Footer element

2. **about.html** - Simple about page demonstrating:
   - Basic page structure
   - Heading and paragraph
   - Link back to home page

3. **contact.html** - Contact form page demonstrating:
   - Form element
   - Various input types (text, email)
   - Textarea element
   - Button element
   - Labels for form elements

4. **image.jpg** - Placeholder image file (to be replaced with actual image)

## HTML5 Concepts Demonstrated

- **Document Structure**: DOCTYPE, html, head, body elements
- **Semantic Elements**: header, nav, section, article, footer
- **Text Elements**: headings (h1-h6), paragraphs, horizontal rules
- **Formatting Elements**: bold, italic, underline, strong, emphasis, mark
- **Lists**: ordered (ol) and unordered (ul) lists
- **Tables**: table, tr, th, td elements
- **Images**: img element with src and width attributes
- **Hyperlinks**: anchor (a) element with href attribute
- **Forms**: form, input, textarea, button, label elements
- **HTML5 Input Types**: email, date, number, color, range

## How to View

1. Double-click on `index.html` to open it in your default web browser

3. Use the navigation links to navigate between pages
