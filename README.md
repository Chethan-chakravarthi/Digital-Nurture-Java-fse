# Digital Nurture – Java

This repository contains my hands-on exercises, assignments, and projects completed during the **Cognizant Digital Nurture 5.0** training program.

## 📌 Course Overview

The repository includes week-wise implementations covering Java, Spring Framework, Spring Boot, Microservices, HTML5, CSS3, JavaScript, Bootstrap 5, Webpack, and Angular.
