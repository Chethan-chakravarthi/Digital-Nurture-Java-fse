# 🚀 Digital Nurture – Week 6: React

## 📋 Overview
This week covers React from the ground up — from basics to a full final assessment project.

## 📁 Module Structure

| Module | Topic | Description |
|--------|-------|-------------|
| Module 1 | React Basics | Installation, project structure, running your first app |
| Module 2 | JSX | JSX syntax, expressions, and rendering |
| Module 3 | Components | Functional & Class components |
| Module 4 | Props & State | Passing data and managing state |
| Module 5 | Event Handling | onClick, onChange, and custom events |
| Module 6 | Forms | Controlled components, form validation |
| Module 7 | Routing | React Router, navigation, dynamic routes |
| Module 8 | Hooks | useState, useEffect, useContext, custom hooks |
| Module 9 | API Integration | Fetch/Axios, REST APIs, loading & error states |
| Module 10 | Final Assessment | Full React mini-project |

## 🛠️ Prerequisites
- Node.js v14+ installed
- npm or yarn
- Basic JavaScript knowledge

## 🏃 Quick Start
Run `npm start` inside any module's project folder to launch at http://localhost:3000

## 📌 Notes
- Each module builds on the previous one
- All projects created with Create React App
